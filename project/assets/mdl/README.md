# Custom costume packs

`m000_mikujp.xpr` -- "Japanese Miku": the JP release's default sailor
uniform, hand-painted over the miku2 (gyaru) texture layout in Blender
and packed to the native XPR format with `tools/glb2xpr`.

Install: copy into the game folder at `game/Media/3ddata/man/mdl/`.
Select in game: F6 -> COSTUMES -> Japanese Miku (applies on next launch).
